# 🚴 SOFTBYKE — Plataforma Web Institucional & Catálogo

> Projeto desenvolvido para a disciplina de Desenvolvimento Web do curso de Ciência da Computação.

---

## 📌 Sobre o Projeto

O **SOFTBYKE** é um portal web focado na apresentação de bicicletas, componentes, acessórios e transparência documental. O layout foi construído em **Dark Mode**, utilizando efeitos de vidro acrílico (*backdrop-filter*) e elementos em tom verde neon (`#beff11`).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica de conteúdo.
- **CSS3:** Flexbox, Grid Layout e custom properties.
- **JavaScript:** Interatividade de menus e componentes visuais.
- **Google Fonts:** Tipografias *League Gothic* e *Poppins*.

---

## 📁 Estrutura de Arquivos

```text
├── index.html          # Página Inicial
├── bicicletas.html     # Catálogo de Bicicletas
├── empresa.html        # Sobre a Empresa
├── produtos.html       # Lista de Produtos
├── galeria.html        # Galeria de Imagens
├── documentos.html     # Documentos, Briefing e Tabelas
├── styles.css          # Estilos Globais
├── scripts.js          # Scripts de Interatividade
└── img/                # Vetores, Logos e Imagens do Projeto
```
